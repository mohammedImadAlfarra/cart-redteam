Limitations & honest reading

  • Dataset is a known, relatively easy benchmark. The very high headline accuracy reflects that attacks in this dataset differ sharply from benign values. The cross-validation above shows the score is stable across folds (not a lucky split), and the leave-one-attack-type-out test shows how performance drops on an attack family the model never trained on — a more realistic signal of generalization.
  • Agent precision/recall are measured against a self-authored answer key. The lab targets and their ground truth were built for this project, so the scan's precision/recall measure "does the agent find the planted vulnerabilities," a controlled benchmark — not real-world precision on unknown applications.
  • Features are rule-inspired. They encode SQL/XSS/traversal cues, so the model partly relies on the same signals as the rule-based scanner; it complements, not replaces, the proof-based engine.
